# LCARS interface audio

These interface clips are canonical *Star Trek* computer effects sourced from
[TrekCore's audio archive](https://www.trekcore.com/audio/).
The class profiles use separate source recordings:

- `bridge-ambient.mp3` is a bandwidth-reduced copy of `TNG Bridge 2` for the
  Galaxy Class interface.
- `intrepid-bridge.mp3` is a bandwidth-reduced copy of `Voyager Bridge` for the
  Intrepid Class interface.
- `intrepid-key.mp3` is derived from the Voyager-era hail effect and supplies
  an era-specific input acknowledgement.
